# 教学数据

`places.geojson` 为本课程人工编写的合成数据，随项目以 MIT 许可证提供。

- 3 个点：2 个 `hospital`，1 个 `park`。
- 名称与坐标组合仅用于编程教学，不代表真实医院、公园或服务信息。
- 每个点都有 `id`、`properties.name`、`properties.category` 和 `geometry`。
- 依据 GeoJSON 的经纬度约定，坐标使用 WGS 84，经度在前、纬度在后，单位为度。
- 第一课暂时假定数据符合上述结构。后续课程再添加缺失字段、错误坐标和无效几何的校验。

以后使用真实开放数据时，需要另外记录来源 URL、获取时间、坐标系和数据许可证。代码的 MIT 许可证不会自动覆盖外部数据。
