# 课程总览：12 节主线课与第 0 节准备课

课程目标：由零基础学习者亲手实现一个可在 GitHub 开源的自然语言空间查询助手，能运行、解释并独立扩展主要功能。

| 课次 | 内容 |
| --- | --- |
| 0 | GitHub、Codespaces、分支与开发环境 |
| 1 | Python 基础、读取 GeoJSON、按类别筛选 |
| 2 | 经纬度与米制距离计算 |
| 3 | 类别与半径筛选、查询结果与距离排序 |
| 4 | 数据和参数校验、错误与空结果处理 |
| 5 | 将 GIS 函数封装为有明确 JSON 输入输出的工具 |
| 6 | 大模型 API、消息与返回结果 |
| 7 | Agent 工具调用执行循环 |
| 8 | 缺失信息、调用失败与循环次数限制 |
| 9 | 项目结构与命令行程序 |
| 10 | GeoJSON 导出、结果与计算依据展示 |
| 11 | 自动测试、依赖管理与安装复现 |
| 12 | 文档、PR 审阅与 GitHub 开源版本发布 |

详细讲义与练习目前准备到第 3 课；后续按主线逐课提供。`roadmap.md` 是按阶段组织的开发路线，一阶段可以包含多节课。
学习进度由自己运行、实现、检查和解释代码来确认，不以材料已经存在作为完成依据。
